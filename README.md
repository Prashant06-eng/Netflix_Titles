# Netflix Data Analysis

## Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a Netflix dataset using Python. The analysis focuses on answering ''5 specific questions'' about Netflix movies and TV shows.

## 📊 Dataset

The dataset contains information about **8,807 Netflix titles** with details such as:

* Title
* Type
* Director
* Cast
* Country
* Release year
* Rating
* Genre
* Duration

## Analysis

The project answers 5 questions using data cleaning, analysis, and visualization techniques.

The analysis was performed using **Pandas, NumPy, Matplotlib, and Seaborn**.

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
